# Game vision and scope

**Neon Foundry Racing** is an original Android-first hovercraft motorsport game, built from scratch. The visual and ownership ambition is a premium walkaround garage, paired with racing that can leave conventional road surfaces behind.

## Planned player journey

1. Walk through the Foundry garage among owned craft.
2. Approach and inspect a craft: exterior, roof, cockpit, hover assembly, rear thrust, and underbody.
3. Customize or upgrade parts, then select the craft to drive.
4. Choose racing discipline, track and event in Race Control.
5. Race on surface, hybrid or fully airborne courses.
6. Receive results, credits, unlocks and return to the garage.

## Three racing disciplines

- **Surface:** Familiar corners, braking zones, overtaking and track design, with hovercraft dynamics.
- **Hybrid:** Solid roads mixed with jumps, gaps, unusual terrain, climbs and real free-flight transitions.
- **Aerial:** A three-dimensional gate course, with genuine pilot control over altitude, pitch, yaw, lift and recovery.

Do **not** imitate flight by moving a craft along an invisible road.

## First playable vertical slice

One high-detail original hero craft; one walkable garage; close inspection; one basic driving/flying proving ground; a single hybrid event; results and a return-to-garage loop.

## Current boundaries

No game systems, craft models, track models or economy have been implemented. We are establishing architecture and production standards first.

The earlier SceneForge repository remains an R&D reference. No old gameplay scripts or meshes are copied wholesale into this new project.
